# Simple Python Calculator with Pytest

Ett enkelt projekt för att lära sig grunderna i Python-uträkningar och automatiserad testning med `pytest`.

## Installation
Se till att du har Python installerat, ladda sedan ner testerna:
```bash
python -m pip install pytest
```

## Köra tester
För att köra testerna med en detaljerad beskrivning, använd:
```bash
python -m pytest -vs
```
